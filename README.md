# Still Palette

**Still Palette** is a powerful color extraction tool that transforms images, photographs, and cinematic stills into beautifully curated color palettes. Designed for filmmakers, colorists, designers, and visual artists, it decodes the visual DNA of any image to help you master color theory and look-development.

## Features

- **Palette Generation** – Upload any image to automatically extract a colorm palette.
- **Interactive Color Picker** – Manually drag colors or pick from the image.
- **Customize** – Add a caption, date and/or the color hex codes.
- **Export** – Just copy or right-click and Save As to download the image.

## Getting Started

### Prerequisites

Make sure you have Python 3.10 or higher installed on your system. 

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com
   cd still-palette
   ```

2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Launch the app:
```bash
python run.py
```
